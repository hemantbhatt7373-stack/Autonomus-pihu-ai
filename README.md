# 🚀 Pihu AI - Autonomous Desktop Co-Pilot

Autonomous Multimodal AI Desktop Assistant & Physical OS Agent.

## ⚡ Key Features
- **Hands-Free Desktop Automation:** Full keyboard/mouse control via PyAutoGUI for system navigation and app workflows.
- **Groq LPU Acceleration:** Ultra-fast function calling and tool execution powered by Groq models.
- **Physical App Integrations:** Automated WhatsApp chat searching, message delivery, and voice/video calling flows.
- **Visual Screen Diagnostics:** Real-time screen capture and vision models for code error inspection and auto-patching.
- **Dual UI Experience:** Seamless switching between a procedural neon Siri-style glow orb and a fullscreen animated avatar.

## 🛠️ Tech Stack
- **Language:** Python 3.11
- **LLM Engine:** Groq API (`llama3-70b-8192`, `llama-3.3-70b-versatile`, `llama-3.2-11b-vision-preview`)
- **OS Automation:** PyAutoGUI, Pyperclip, Subprocess
- **Interface & Audio:** CustomTkinter, Tkinter, Pygame
